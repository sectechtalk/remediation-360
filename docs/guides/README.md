# r360 how-to guides

Task-focused guides for operators. New to r360? Start in the app at **New hire > Overview** (the page r360 opens on). Each one ends with the exact PowerShell to run on DEVICE02.

| Guide | Use it when |
|---|---|
| [Fast path (Defender) or slow path (Intune)](fast-or-slow-path.md) | You need to decide whether to act on one PC now through Defender or ship a reviewed fix to many PCs through Intune. |
| [What's supported by license and join state](whats-supported.md) | You need to know what r360 can do on a PC given its user's license (none, Business Premium, E3, E5) and whether it is Entra joined, hybrid, registered, AD-only or not joined. Includes the r360 agent option. |
| [Licenses by feature](licenses-by-feature.md) | You need to know what the company and each operator must be licensed for to use each part of r360: Intune, Defender, Exchange, GitHub, Azure, ServiceNow. |
| [Make a Windows device work with r360](device-requirements.md) | You want to know what a PC needs (join, Intune, license, signing certificate, Defender) before r360 can manage it. |
| [Set up and use email-driven change requests](change-requests-email.md) | An outside organization asks for a change by email and you want it numbered, tracked on GitHub and summarized. |
| [Work with ServiceNow from r360](servicenow-best-practices.md) | You search ServiceNow, keep shared queries, or link ServiceNow items to r360 change requests. |

Feature reference: [change-requests.md](../change-requests.md), [servicenow.md](../servicenow.md), [deployments.md](../deployments.md).
